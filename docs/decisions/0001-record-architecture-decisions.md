# 0001. Record architecture decisions

- Status: accepted
- Date: 2026-10-01
- Supersedes: —

## Context

Decisions were scattered across a plan file, chat and code comments; agents and new contributors cannot tell what is settled.

## Decision

**Record each decision as a lightweight MADR file in `docs/decisions/`, with a generated index and a `just docs` freshness gate.**

## Consequences

- One decision per file, <= 1 page: Context, Decision (one bold line), Consequences.
- `docs/decisions/README.md` is generated by `scripts/check_docs.py`; never hand-edited.
- A change to verdict/score/schemas must touch VERDICT-LOGIC, schemas/CHANGELOG or an ADR (`just docs`).
- `proposed` ADRs older than 30 days fail `just docs`.
